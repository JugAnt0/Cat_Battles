# Paka's Domain

**Paka's Domain** is a 2D pixel-art platformer built with the Godot game engine.

## Gameplay

The game features simple platformer mechanics:

* **Movement:** Arrow keys or **A / D**
* **Jumping:** **Spacebar** or **W**
* **Hazards:** Falling off the map or getting hit by raindrops resets the level

## Project Structure

The repository is organized into three main sections:

### Scenes

Contains the main game scenes, including:

* Main menu and lounge
* Level selection menu
* Skin selection menu
* Player character
* Enemies and hazards (raindrops, clouds)
* Levels 1–10
* Lock and progress systems for unlocking levels
* Particle effects (snow)
* End credits scene

The game also includes multiple playable characters:

* **Panda** – an all-black kitten
* **Bellist** – a yellow and orange striped cat
* **Flora** – a black and white kitten
* **Shany** – a Siamese cat

### Scripts

Contains the **GDScript** files that control gameplay logic, including:

* Player movement and jumping
* Camera behavior and animations
* Level progression and unlocking
* Menu navigation
* End credits logic

### Sprites

All pixel art assets used in the game.
Sprites were created by me using **Aseprite**.

## Built With
